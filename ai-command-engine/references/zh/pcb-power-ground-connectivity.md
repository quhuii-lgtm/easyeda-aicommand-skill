# 电源地接入与实铜连通验收

先找出必连焊盘和确认过的电源输出、地输入或参考面锚点。分别追踪模拟取样回流、数字信号回流和负载电流。按原理图和器件要求确定汇接点，不因位置近就并接。

| 验收到哪一级 | 需要证明什么 |
| --- | --- |
| 局部焊盘组 | 必连焊盘由实际同网铜连接。 |
| 换层点 | 局部组接触过孔，过孔镀铜且跨度覆盖预期层。 |
| 实铜面 | 在对应层直接接触或经真实热焊辐条到达连续填铜。 |
| 主干锚点 | 沿实际焊盘、线、孔和实铜到达已确认的供电或回流锚点。 |

记录实际接点的网络、图层、坐标及所用 PCB 修订。检查铜区孔洞是否切断路径。同名网、过孔落在铜区边框内或没有飞线，都不足以证明接入主干。

## 刷新填铜与矛盾处理

- 布线可能影响供电或回流时，AI 根据当前实填、接点、间距和走线空间判断是否设置禁布及保护范围。用 `pcb.planCopperKeepouts` 查看建议和跳过项，再用 `pcb.applyCopperKeepouts` 应用合适的方案。被跳过的铜区可按已核实的几何选择局部禁布或调整路径。

- 区分新增或调整铜区与刷新既有填充。刷新仍会改变实铜，应遵守任务对重铺的要求。填充未刷新或无法读回时，标出待验区域。重铺后复查既有电源、地和参考面。
- 重铺时把受影响的电源地网络传给 `pcb.rebuildPour` 的 `protectNets`。重铺后核对飞线、DRC 和实际铜路。发现新增断接或读回失败时暂停后续保存，保留当前铜形供核查。已经发生的重铺不会自动撤销。
- 用 `pcb.getPourFillReadback` 读取可用填充，用 `pcb.reviewCopperShape` 核对支持的铜形和所选截面。结合焊盘、走线、过孔和 DRC 读回。现有命令不自动证明完整跨层连通、铜岛或全区最窄处。需要时用实际几何逐段补查，缺证据标为未确认。
- 原生断连与实铜读回不一致时，保留原生结果和对应修订。逐段核对焊盘、线路、过孔、实填和热焊到锚点的路径。怀疑仅替换了告警代表对象时，以网络、图层、位置和实际几何为依据。
- 分别报告原生告警和独立连通结论。只对核对过的保存版本下结论。不要盲加冗余线路或永久忽略该类告警。
