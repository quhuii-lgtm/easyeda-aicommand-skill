## A4 分页预排

画之前读取目标图页的实际纸型和边界。按相同坐标单位划出图签、页边和其他保留空间。
列出本轮完整功能块。每块预估符号、引脚出线、标签和属性文字所需的范围。
先排一页。放不下时把完整功能块移到下一页，重新核算两页空间，并列出受影响的跨页网络。
按项目约定确认分页范围后再绘制。

用同一 [检查脚本](../../scripts/check-schematic.mjs) 预检。设计 JSON 设置 `stage: "planning"`，用 `regions` 列出当前页的功能块 ID。
在 `layoutPlan` 填 `currentPageId`、`pages: [{ id, paper: "A4", bounds, reserved }]` 和 `blocks: [{ id, pageId, bounds }]`。
每个完整功能块只用一个 ID。已获授权并单独确认的子功能可各用一个 ID。
所有边界用 `[x1, y1, x2, y2]`，`reserved` 是保留矩形的数组。读回 JSON 填 `page`、`pageId` 和宿主实际的 `pageFrame: { paper, bounds }`。
绘制后沿用分页计划，脚本用实际区框核对预留范围。

## 必须执行的绘制顺序

以下步骤适用于新绘和本轮修改范围；已有正确内容直接复用，不要求用户逐步确认。

1. 读取目标图页和现状，列明本轮功能区、所属器件、引脚网络及允许的 NC。
2. 新绘功能区先画带标题的分区框，再放置器件；只列分区名称或只摆器件不算已画分区。已有框和标题符合要求时直接复用。
3. 放置后读回实际位号、引脚端点和朝向；先调整器件、支路及文字空间，再接线。
4. 逐区按后文规则选择就近直连、汇流线或标签；命令和宏的默认画法不符合要求时，改用适合的连接命令。
5. 每区完成后核对框、标题、器件归属、导线及标签附着，并查看最新图像的局部放大图；发现漏框、穿符号、遮字或多余标签时，在授权范围内修正再检查。
6. 最后按连接表核对网表、运行 ERC/DRC、检查整页并保存；缺少图面或连接检查时，只能报告已完成的部分。

## 功能区布局与引脚接线准备

- 多功能区图纸必须按功能画出分区框和标题，先规划各区的位置、阅读顺序和标题空间。
- 区框按实际符号、引脚出线、标签及属性文字的范围留余量。
- 大型模块和高引脚数器件按实际占用单独留位。
- 元件间距按符号尺寸调整，不直接套用其他工程的固定坐标。
- 批量放置前整理料号、预期位号和引脚网络表。
- 已取得的器件资料按料号复用。
- 当前命令支持批量查询时优先批量查询。
- 引脚网络表以器件身份和引脚编号定位，多单元器件同时区分单元。
- 核对 `buildBlock` 返回的 `refMap` 后，再对照实际位号和引脚接线。
- 电源、地、信号和合法 NC 分别列明。
- 未分配引脚先核实用途。
- 相近同网引脚优先直连。
- 需用标签时，从实际引脚接线端向符号外侧引出短线。
- 标签间距按当前单位、文字和邻近引脚调整，不统一套用上游的 10 单位偏移。
- 生成后逐区核对实际框和可读标题，检查器件、标签和文字是否留在所属区框内，必要时调整布局或扩大区框。

这些要求用于规划和读回检查，不代表 `buildBlock` 已实现按符号尺寸自动避让。
已有图纸只在授权范围内调整，不因套用功能框而重排全图。

借鉴来源：[官方原理图放置与网络引出技能](https://github.com/easyeda/easyeda-enhanced-schematic-skill/blob/main/SKILL.md)（2026-10-10 核查）。
这里只吸收布局与批量准备方法。

执行仍使用本插件命令及现有保存验收流程。

## 图纸怎么画

新绘图和后续优化都采用以下要求。
直连长度和摆放方式采用本用户的默认偏好，项目明确要求优先。
图上的距离不能当作 PCB 电气距离。

## 分区与网络命名

- 按功能分区，按阅读顺序排列。
- 重复通道保持相同的功能关系，并逐个检查。
- 同一电气网络使用一个明确的网络名。
- 不在同一导线上放置异名标识或标签。
- 发现异名直接相连时，先核对原先确定的接法。
- 确认是同一网络后统一命名。
- 需要保留不同网名时，明确指定位置的连接方式。
- 不用灵活模式的多名称并网作为常规画法。
- 使用主图和子图时，核对两者端口与网络的对应关系。
- 局部名、端口名和全局名可以不同，但必须对应正确。

## 复用模块

- 记录来源版本、工作条件和已经完成的检查。
- 未完成模块标明待定接口，不能当成可生产模块。
- 检查电平、方向、供电域和未上电状态。
- 检查脚序、极性、封装、外围和电流返回。
- 子图模块要检查与主图连接的端口。
- 先验证一个单元，再逐个检查位号和通道网络。
- 旋转或镜像后的实例要重新检查脚位和几何位置。
- 原理图复用通过不代表 PCB 可以直接复制。
- 母版修改后重新检查受影响实例。

## 功能区先行

新绘功能区先调用 `schematic.placeRegion` 画框和标题，或复用 `schematic.buildBlock` 已创建的框；不要重复画框。用 `listRects` 核对框的 `span`，并核对标题和实际图像；只返回框 ID 不代表标题成功。

`placeRegion` 的 `x,y` 是框左上角及上沿，`buildBlock.region` 的 `x,y` 是左下角；两者均按 +Y 向上计算，不能照搬同一个 Y。尺寸按器件、引脚出线和文字实际占用调整。

`schematic.buildBlock` 是初放与接线宏，不保证符合布局和直连要求。默认电源网及多引脚网会逐脚放标签；显式 `style:"wire"` 也仅在实际解析为两个引脚时直连。需要区内多脚就近直连时，可用 `nets:[]` 只完成框和器件初放，读回 `refMap`、实际引脚并调整位置后，再用连接命令逐区接线。尚未接线时不能报告功能区完成。

## 图元定位与标题修改的版本要求

当前 EDA 4.1.78 下，`schematic.modifyText`、`schematic.getPrimitivesInRegion` 和 `schematic.getPrimitiveAtPoint` 有版本保护，会拒绝执行并提示需要 EDA 4.2。`schematic.modifyText` 的宿主原生修改在 4.1.78 保存重开后会回退。不要将拒绝执行视为功能通过；EDA 4.2 的实际执行和持久化仍需核验。
