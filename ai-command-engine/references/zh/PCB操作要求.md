# PCB操作要求

本文件维护具体绘制、修改和结果核对要求。
项目提供已确认的范围、预期连接和设计条件。

阶段验收和项目记录按项目约定管理。
在线命令与参数从技能入口同时选读对应命令页，以当前安装版帮助为准。
离线生成或其他后端仅采用适用的图纸与设计要求，不据此发起在线写入。

## 必须执行的操作顺序

先明确是布局、局部修改、整板布线还是制造交付。只执行本轮及受影响内容，已有合格部分复用；未提供的工艺、机械或电气参数不猜测，只继续不依赖缺项的工作。

1. 读取当前工程、PCB、原理图关联、器件、真实焊盘及网络；原理图更新到PCB仍由用户在EDA界面发起，更新后重新读回，并按下节询问是否需要分组。
2. 核对板框、孔槽、固定接口和禁放区域，再核对图层、适用的物理叠层及实际网络/分层/区域规则。修改前明确允许移动、改线和必须保持的对象。
3. 按后文摆放顺序安排固定接口、关键局部电路、主控和普通器件；位置按真实连接、焊盘及返回路径确定，不按位号或芯片中心机械排队。分组整理只在选用后执行。
4. 正式布线前检查真实焊盘出口、共用通道、过孔及全部受影响层的空间；对受限区域按需要成组试布或核对实际几何。发现冲突先调整相关器件或路径，不能用自动布线成功掩盖布局问题。
5. 先完成关键回路和受限线路，再处理普通线路及全部必连电源、地焊盘；选用的扇出、差分、等长和自动布线工具按对应流程，读回后核对实际路径和连接。
6. 需要扇出和改线的部分完成后重建覆铜，核对实际填充、孤岛及返回连续性，再整理丝印与接口标识。后续再改铜形或相关网络时，重查受影响覆铜和连接。
7. 核对网络、关键回路、机械装配和图面，整板最终版本运行完整DRC；制造交付再按实际工艺执行适用的DFM/SMT检查和文件核对。
8. 按本文件完成检查、保存及重开要求交付，逐项报告范围、依据和缺项；只完成布局或局部操作时，不能称整板已布通或可生产。

局部布局与布线可迭代调整；进入依赖步骤前先解决影响它的必要条件，不重新推进无关阶段，也不要求用户逐步确认。

## 可选功能与提示时机

器件分组、自动布线及下列自动整理/优化功能均为可选方式，不是每块板必做的步骤。条件具备且本轮尚未选择时，AI主动说明用途和影响并询问；相关选项可合并询问，已有明确选择直接沿用，不重复确认。

| 可选功能 | 何时提示 | 选择后怎么做 |
| --- | --- | --- |
| 器件分组 | 原理图导入/更新到PCB并完成读回，器件及来源可核对时，询问是否按原理图功能区分组。 | 需要时预览 `groupBySchematicRegions` 的范围和位置，再执行、读回；不需要则不分组，继续常规布局。固定器件和已有走线的保留范围先明确。 |
| 自动布线 | 本轮包含布线，布局、规则和受限通道检查完成，DSN及层映射、在线服务或外部CLI条件具备时，提出是否采用自动布线。 | 在线方式按导出DSN、启动任务、查询、取回SES、显式导入及验收执行；外部CLI按导出DSN、运行已选CLI、显式导入SES执行。选择不用自动布线则按已授权的常规方式处理。 |
| 密脚扇出 | 密脚焊盘或换层出口需要扇出，真实焊盘、网络、线宽、孔和障碍条件已明确时。 | 先出计划，核对可执行范围，再执行和检查；不选宏仍须满足必要的引出及连接要求。 |
| 差分布线/补长工具 | 已确认差分或时序要求，网络、参考面、目标及容差明确，且需要相应几何工具时。 | 按当前支持范围规划与执行，不为普通控制线无故补长；不选工具不等于免除已确认的差分或时序要求。 |
| 自动铜皮/焊盘外扩 | 已明确局部载流或连接需求，目标焊盘、网络、层及所需尺寸可核对时。 | 说明会增加或改变哪些铜形，选用后先计划、再执行及读回；不对无关焊盘自动扩形。 |
| 网络文字丝印 | 网络已核实，需要额外网络标识，且有可检查的丝印空间时。 | 说明标识范围和影响，选用后预览、生成，再核对开窗、板边和可读性。 |

- 未回复时不执行可选功能，可继续不依赖该选择的读取和检查；条件缺失时说明缺项，不把提议当作已获准执行。
- 用户选择不需要时沿用常规流程，不为通过验收补做该功能；条件或范围实际改变后才说明新原因再提议。
- 常规读回、已授权的必要走线/覆铜重建及验收按流程执行，不作为每步都要询问的菜单。
- 已确认的电气、机械和制造要求仍须满足；可选的是工具或整理方式，不是是否遵守设计要求。

## 板框和制造规则

- 先确认板框、孔槽、固定接口、装配面和高度。
- 接口位置和朝向按机械图、配套插头和装配方式确定。
- 检查插头插到底时是否被板边、外壳或相邻器件挡住。
- 为线缆弯曲、锁扣和拔插工具留空间。
- 板对板连接器核对配对板的位置、方向和高度。
- 安装孔周围按实际螺钉、垫圈和支柱留空间。
- 分板边缘、工艺边和贴装空间按实际生产方式检查。
- 只锁定已有明确位置要求的器件。
- 按实际工艺设置线宽、间距、铜到板边和孔规则。
- 分清钻孔尺寸与成品孔尺寸。
- 分清镀铜孔、非镀铜孔及塞孔、填孔要求。
- 检查网络、分层和区域规则实际作用于哪些对象。
- 不只检查默认规则。
- 有绝缘、爬电或阻抗要求时，单独核对依据。

## 层叠和电流返回

- 写清每层用途、材料、铜厚和介质厚度。
- 分别记录图纸铜厚、检查采用的铜厚和订单铜厚。
- 三者不一致时，写清差异和处理状态。
- 未确定的订单工艺标为待确认。
- 已确定但未提交的工艺标为拟下单参数。
- 修改检查参数不代表修改了图纸层叠。
- 铜层数量正确不代表物理层叠正确。
- 结合布线密度、供电和板厂工艺选择层叠。
- 信号变化次数少，不代表每次高低电平切换都很慢。
- 关键线路要明确所用层、参考铜面和返回路径。
- 检查参考面是否被孔、槽和走线切断。
- 层名叫 GND 不代表实际铜面连续。
- 返回电流会分布在铜面上，不只沿示意图的一条线流动。

四层板可比较以下方案，没有通用首选。
S 表示信号，G 表示地，P 表示电源。

| 从顶到底 | 主要检查点 |
|---|---|
| S / G / P / S | 底层线路的电源参考面是否连续；换参考面时如何返回 |
| S+P / G / G / S+P | 外层供电是否够用；两层地之间如何连接 |
| S / G / P+少量S / G | 内层信号实际参考哪一层；走线是否切碎电源区 |

- 相同层序也要检查具体介质厚度和阻抗。
- 两层板检查实际铜面能否提供返回路径。
- 六层板不能仅凭层数判定更好。
- 没有真实制造层叠时，不称阻抗已通过。
- 快速或敏感信号避免跨参考面缝隙。
- 信号换层时，检查返回电流如何换层。
- 同地参考面之间按实际需要安排地过孔。
- 地过孔不能连接不同电位的参考面。
- 地参考转电源参考时，检查交流返回条件或调整布线层。
- 不给所有换层信号盲加电容。
- 差分线也会有两根线同向变化的电流，其返回路径仍要检查。
- 不只因 AGND/DGND 名称不同就切割地面。
- 不为补回流破坏隔离槽、天线净空或特殊感测结构。

## 差分信号

- 用 `knowledge.query` 的 `query: "USB"` 查询接口相关经验，再按具体标准、器件资料、板厂叠层和项目约束确定阻抗、间距、等长及参考面。
- 知识库数值仅供初步规划；不得把单一接口的经验数值当作所有差分对的固定规则。
- 完成后核对差分对规则、两根线的全程间距、长度差、参考面连续性和换层位置。


### 阻抗设计参数与订单一致

先选定板厂可制造叠层再计算，或先按已有订单的实际参数计算。两种方式都使用同一份选定参数，设计和下单逐项核对。

- 记录板厂、叠层名称或代码、来源与查询日期、层数、成品板厚、材料、内外层铜厚。
- 按所用官方计算器记录阻抗模型、目标值、信号层、参考层、差分线隙或共面线到地铜间距，以及计算得到的线宽。模型采用的介质厚度、Dk、阻焊等参数从实际来源记录，不填猜测默认值。
- 分清拟选参数、已用于计算的参数和订单已确认参数。下单核对结构、材料、厚度、铜厚、阻抗测试与公差；不一致时重新核算，不能只核对层数。
- EDA中记录的物理叠层不代表订单已选择相同结构，阻抗估算也不等于制造保证。

依据：[嘉立创阻抗计算器指南](https://jlcpcb.com/help/article/user-guide-to-the-jlcpcb-impedance-calculator)、[标准层压结构](https://jlcpcb.com/help/article/multi-layer-pcb-standard-laminated-structures)、[EDA物理叠层与下单说明](https://prodocs.lceda.cn/en/pcb/tools-layer-manager/)。

## 复制多层板后的检查

- 复制四层板或其他多层板后，核对目标板的原理图关联。
- 核对实际铜层顺序、介质层和总板厚。
- 核对各层用途和铜厚是否符合本次设计条件。
- 要求保留原板时，确认原板仍在且内容未变。

## 空网络焊盘

- 空网络焊盘逐个核对脚号、用途和已确认的接法。
- 分清漏接、未使用信号脚、允许悬空的功能脚和机械焊盘。
- 允许悬空的功能脚必须有对应型号的资料依据。
- 机械焊盘按实际用途核对是否需要接地或其他连接。
- 工具无法确定网络不代表设计一定有错。
- 分类确认不代表工具已经完整检查该焊盘。
- 记录每个告警的分类、判断依据和未完成检查。
- 不为消除告警强行补接地或修改网络。

## 摆放器件

### 摆放顺序

1. 先放固定接口和机械相关器件。
2. 按供电、控制、采样和外接接口确定功能区的相邻关系。
3. 先安排旁路、驱动、自举、反馈和时钟等关键局部电路。
4. 为主电流、重要信号、换层孔和返回路径留出空间。
5. 根据全部已用接口调整主控位置和朝向。
6. 核对一个重复通道后，再展开其他通道。
7. 检查受限引脚出口和共用通道能否布线。
8. 最后调整普通器件的间距、朝向和对齐。

### 功能区和配套器件

- 关键芯片按对应型号、封装和工况的原厂布局要求检查。
- 分清原厂必须条件、建议和本项目采纳的做法。
- 把要求落实到具体焊盘、走线和返回路径。
- 不照搬示例板坐标、固定距离、网格或旋转角度。
- 选用分组时按真实连接关系整理，不只按位号前缀或器件种类分组，也不在铜层或丝印层自动画区框；未选用仍按真实连接、焊盘和返回路径布局。
- 每个配套器件明确所属引脚、接口或回路。
- 配套器件跟随真实引脚和返回路径摆放，不围绕芯片中心排队。
- 频繁互连的功能区先安排相邻位置和连接通道。
- 移动或旋转主控时，核对全部已用接口、配套器件和邻区影响。
- 飞线交叉、中心距离和总飞线长度只用于筛选候选。

### 各类局部电路

具体型号要求由 component-pcb-profiles 维护。
未核实的型号要求先查对应原厂资料。

| 对象 | 摆放检查 |
|---|---|
| 去耦与供电 | 检查对应供电脚、焊盘、过孔和返回组成的实际路径，不只看电容距离。 |
| 电源转换 | 按输入、转换和输出安排路径，并检查高频回路、自举、反馈和散热空间。 |
| 驱动与功率开关 | 检查驱动和开关回路，并避免功率路径干扰栅极与检测路径。 |
| 晶振与时钟 | 围绕时钟引脚安排晶体和负载器件，护地及下方布线按具体指南处理。 |
| 通信接口 | 保护、端接和分支按实际作用位置及接口拓扑摆放。 |
| 保护与续流 | 检查保护点、故障来源、返回和受保护路径的位置关系。 |
| 模拟与传感 | 输入、参考和滤波避开干扰，传感器位置和轴向符合测量目的。 |
| 分流与精密反馈 | 按实际取样端安排器件，并检查功率压降和热源的影响。 |

位号位置、角度、字号和显隐用 `pcb.modifyComponentAttribute` 修改，位号文本保持；安装孔与独立焊盘分别用 `pcb.placeHole`、`pcb.placePad`。按当前窗口帮助核对孔型、镀层、铜及阻焊，并读回几何和网络；不能用普通过孔代替NPTH安装孔。

### 散热、装配和对齐

- 热源附近的器件核对实际温度条件和允许温漂。
- 为散热铜、散热孔、散热器和实际气流留空间。
- 不为分散热源而拆散必须紧凑的功率或驱动回路。
- 大件按真实本体和装配空间检查，不只看焊盘包围盒。
- 双面和多层板检查全部受影响层的障碍、穿板引脚及配合结构。
- 小器件两端的铜连接和受热差异按实际焊接工艺检查。
- 电气和机械条件允许时，同类器件可统一朝向和间距。
- 不为整齐拉长关键回路，或仅因任意角度和不等距判错。
- 极性和 1 脚标识应便于装配和检查。
- 机械、安全、电气和制造的必要条件冲突时调整方案，不按固定排名豁免要求。

### 重复通道和复制

- 模板先明确输入、输出、控制、配套器件和返回关系。
- 每个实例核对脚号、极性、网络、朝向及所在位置的障碍。
- 共享供电和共享返回单独检查。
- 有实际障碍或工况差异时，允许通道采用不同摆法。
- 复用过孔布局后，逐通道核对网络、障碍、载流和散热条件。
- 模板通过不能代替全部实例检查。

## 烧录和测试位置

- 布局时先为烧录夹具、探针和拆焊工具留出空间。
- 按实际测试阶段，检查装配后能否接触到焊盘。
- 避开会挡住探针的连接器、散热器、屏蔽罩和外壳。
- 按所用探针或夹具确定焊盘尺寸、间距和接触面。
- 探针接触区开阻焊窗，并检查实际导出结果。
- 裸探针焊盘通常不开锡膏窗，焊线或其他工艺另按用途设置。
- 丝印标清必要的针序、信号和方向，不覆盖接触区。
- 烧录焊盘的顺序和方向与夹具一致，并考虑防反接。
- 测量点附近提供合适的参考地接触位置。
- 参考地必须属于被测电路，不跨接不同隔离域。
- 高速、射频、晶振和敏感模拟节点先评估测试焊盘及支线的影响。
- 探头负载可能改变信号，测量方式也要一起考虑。
- 0Ω 电阻放在便于拆装的位置，并保留两端测量空间。
- 需要断开的连接不能被铜面或其他支路绕过。
- 电源路径上的 0Ω 电阻及两端走线要满足实际载流要求。
- 核对所有烧录焊盘和测试点的实际焊盘网络。

## 安排布线路径

- 优先处理关键回路和最难引出的线路。
- 正式布线前，对有疑问的受限出口和共用通道成组试布或检查真实几何空间。
- 检查采用真实焊盘、所在层、线宽、间距、孔和全层障碍。
- 元器件无重叠不能证明布局可布通。
- 试布结论只覆盖已检查范围，预测路径与已布路线分别记录。
- 共用通道必须同时容纳相关线组，不能逐根通过后重复占用同一空间。
- 规划两端引出、主通道、分支、换层和返回。
- 未布引脚及电源、地也要保留出口。
- 不为排列整齐擅自更换芯片引脚或连接器针序。
- 简单直通道可用线宽之和、间距之和及两侧净距估算宽度。
- 转弯、分支、过孔和返回所需空间另算。
- 不统一规定顶层横走或底层竖走。

## 功率、信号与采样

- 从电源到负载，再到返回端，逐段检查电流路径。
- 检查器件、连接器、焊盘、窄铜、孔组和铜面。
- 按工作条件检查电流、压降、损耗和温升。
- 按开关状态识别快速变化的电流回路。
- 按芯片要求处理开关节点、栅极和自举回路。
- 大铜面不能替代回路检查。
- 通信线路按器件、边沿、负载、协议和线缆检查。
- 差分阻抗和时序要求按实际接口及层叠确定。
- 测量源端到各接收端的实际路径。
- 整网铜长不能代替端点路径或时序偏差。
- 多针同网连接器要检查全部必连针。
- 双向总线按实际驱动状态检查。
- 分支采用何种接法，应由接口和负载决定。
- 普通控制线和 PWM 线没有等长要求时，不必绕蛇形补长度。
- 采样正负端按真实取样位置布线。
- 不把禁止共享的功率压降段混入采样路径。

## 大电流逐段记录

- 按实际连接顺序记录连接器、铜线或铜面、器件焊盘、换层孔组和返回路径。
- 每段写清持续电流、峰值电流和相应持续时间。
- 每段记录最窄位置、实际尺寸和所用铜厚。
- 孔组另记孔径、孔数、孔壁镀铜厚度和连接方式。
- 分清钻孔尺寸与成品孔尺寸。
- 缺少的参数标为待确认，不能用工具默认值补齐。
- 每段记录载流、压降和温升的检查依据及待验证项。
- 外层铜厚不能代替过孔孔壁镀铜厚度。
- 过孔数量不能代替孔组载流和温升检查。
- 大片铜和 DRC 无错误不能单独证明载流能力。
- 具体器件的散热孔要求由 component-pcb-profiles 维护。

## 过孔和铺铜

- 信号孔、地孔、载流孔和散热孔分别检查。
- `placeVia` 会读回过孔并请求飞线计算；`connectivityVerified:false` 表示跨层连通尚未确认。刷新后用连接检查核对实际状态。
- 先完成需要的扇出，再建立或重建覆铜；多个网络的扇出计划应逐个生成并逐个执行，执行后重新读取障碍和可用路径。
- 减少换层时保留必要的返回和散热路径。
- 并联孔的能力不能简单按数量相乘。
- 盘中孔须由封装和选定制造工艺支持。
- 铺铜检查网络、层、边界、间距和连接方式。
- 检查优先级、孤岛处理和制造优化设置。
- 热焊盘连接兼顾电流、散热和焊接。
- 修改相关图形后重建铺铜。
- 确认自动重建设置是否生效。
- 检查实际生成的铜面是否连续。

## 改线和比较

- 先写清可移动器件、可改走线和必须保留的连接。
- 单个出口问题先做局部调整。
- 共用通道有问题时，一起检查相关功能组。
- 反复绕同一个障碍时，先检查布局原因。
- 删除和推挤后检查分段、裁剪、邻线和范围外接点。
- 比较方案时使用相同端点、工作条件和范围。
- 同时记录所有受影响接口的路径、换层、返回和邻区代价。
- 未找到更好路线不能证明当前换层必不可少。
- 更短或孔更少不能抵消电气、机械和制造问题。

## 修改前后比较

修改、删除及保存读回按[PCB操作流程](commands-pcb.md)执行。比较修改前后的网络与几何位置，并保留无法解释的差异。
- 同网走线合并后，核对端点、路径、所在层和线宽。
- 铺铜生成 ID 变化时，另核对边界、填充几何和连接。
- 仅生成 ID 变化与实际铜面变化分别报告。

## 丝印和接口标识

- 分别检查独立文字、器件位号和封装内标识。
- 按实际工艺检查字高、笔画宽度和最小间距。
- 放大文字后，重新检查文字与焊盘、阻焊开窗、板边和相邻文字的间距。
- 底面文字按实际底面视图检查方向和针序。
- 反相文字检查背景范围和字符是否完整。
- 工具不能修改器件属性时，列出未完成对象。
- 尺寸检查通过不能代替图面检查。

## 完成检查

先写清PCB、图页/板号、本轮对象和验收阶段；局部任务只验目标及受影响接口。原理图连接表、板框机械条件、关键网络要求及制造工艺以已确认版本为准。

### 验收项目、方法和通过条件

| 项目 | 怎么验 | 通过条件 |
| --- | --- | --- |
| 设计对应与网络 | 用 `listComponents`、`getComponentPads`、`listNets` 和适用的网表/网络图元读回，对照器件、封装、针序及全部必连焊盘；重复通道逐实例核对。 | 无漏件、错封装、错极性或意外改网；空网焊盘已按用途确认，不为清告警强行补地。 |
| 板框、孔槽与机械 | 对照机械图及实际板框、孔槽、器件位置与外形，查看顶底面及适用的三维/装配资料，检查高度、插拔、固定和测试接触空间。 | 尺寸、位置和朝向满足已确认条件，无本体或装配干涉；仅焊盘不重叠不能判机械通过，缺少必要资料时注明未完成。 |
| 层叠和规则 | 读当前可用的图层、规则及物理叠层记录，对照信号层、参考面、铜厚、介质及网络/分层/区域规则；接口不支持时用适用资料或界面核对。 | 采用的设计条件明确，实际作用对象正确；铜层数或层名不能代替真实叠层，不以默认参数填补未知。 |
| 布局与可布线性 | 用真实焊盘、`checkPlacement` 及最新局部图检查功能组、关键配套器件和出口；受限共用通道按线组、线宽、间距、孔和全层障碍核对。 | 必要局部电路和返回路径位置合理，相关线组有可行空间；碰撞候选须复核，工具跳过或焊盘包围盒近似不算完整布局检查。 |
| 走线、过孔与连通 | 用 `listLines`、`listVias`、`getNetInfo`、`getNetPrimitives` 及适用DRC核对实际端点、网络、层、线宽、铜外径/钻孔和焊盘接触；放大关键接点。 | 本轮连接符合预期；整板布线验收无未处理的必连断路。飞线刷新、非空ID、分段数量或自动布线服务完成均不能代替连通检查。 |
| 关键电气路径 | 按项目及原厂要求逐段核对功率路径、取样、参考面、回流、换层、差分及长度；用实际几何和选定参数计算或核对。 | 必需的载流/压降/温升、阻抗/时序及返回条件满足依据；不适用项注明，工具不能覆盖的内容补查，缺数据不称通过。 |
| 覆铜与丝印 | 用 `listPours`、`getPourFillReadback`、`checkSilkscreen` 及最新顶底面图核对实际铜面、开窗、位号、极性、板边和针序。 | 需要的铜已填充且连接/连续性正确，丝印清楚可读；边框、no-fill、来源候选或complete:false不能代替已核实结果。 |
| DRC与制造 | 整板最终版运行 `runDrcDetailed` 并检查完整覆盖；制造交付按实际输入执行 `runDfm`、`runSmtDfm` 及 `checkManufacturingProfile`，核对制造文件和订单条件。 | 无未解决错误，其余告警按项目已确认的方式处理；工具不支持、跳过、近似和unknown逐项补查或列未完成，不改规则或默认工艺掩盖问题。 |
| 图面与保存 | 查看修改后的顶底面、关键局部及适用层图，核对对象和当前PCB；按下节保存/重开，比较目标与非目标内容。 | 图面及保存状态与本轮检查一致；旧截图、局部DRC或命令成功不能作为整板通过依据。 |

布局、布线、电气、机械和制造分别给结论。仅布局或局部修改时，尚未开展的整板布线/生产项目注明不在本轮范围，不得顺带报通过；制造交付缺少必要资料则列未完成。实时或自定义DRC不冒充完整检查，清标记不等于修复。

### 保存与重开范围

- 新绘整板、整板正式交付：写入结束且保存确认后，关闭并重开受影响PCB，核对身份、器件属性、焊盘网络、线路/过孔、规则、实际覆铜及最新图面与保存前一致。
- 普通局部调整，包括位置、角度、丝印、属性、增补线路或常规重铺铜：核对目标、受影响连接及非目标内容并保存，不因此要求每次重开整个工程。
- 本轮交付涉及删除/更换器件或既有路由、修改网络或层叠、复制PCB，或明确要求持久性检查时：保存后重开受影响PCB并检查相应内容，不只比较图元ID或数量。
- 未重开只报告“已保存，未验证重开”；实际读回核对后才报告“保存重开已验证”。写入或保存结果未知时先核实原操作，不强行关闭、重发或用保存掩盖问题。

### 验收结果怎么报

写明PCB、板号/版本、本轮对象及布局/布线/制造等阶段；上述项目分别列行，多功能组注明范围，不粘贴全部原始回包。

| 项目及范围 | 结论 | 检查依据 | 未解决或未完成项 |
| --- | --- | --- | --- |
| 功能组/网络/对象及验收项目 | 通过／不通过／未完成／不适用 | 当前对象读回、路径/规则比较、实际查看的图像或DFM文件结果。 | 具体问题、缺少的检查及原因；无则写无，不适用时说明。 |

保存项写明实际保存/重开状态。任一适用项不通过则整体不通过，必检项未完成不能报告整体通过；局部通过不扩大为整板、可生产或实物性能通过。参数或规则改动后，只重查受影响项目和依赖检查。

## DRC之后执行DFM

本节用于制造交付；布局或普通局部任务不要求顺带下单。整板完整DRC通过后，按本次拟下单工艺执行PCB DFM及适用的SMT制造装配检查。
从技能入口直接选读DFM命令说明，核对当前版本、参数与覆盖限制。

- 核对目标PCB、保存版本、板材、板厚、铜厚、层叠及装配工艺。
- 对照图纸、检查输入和拟下单工艺，记录差异与处理结果。
- 核对返回的完整性、逐项结果和覆盖范围，不能只看API成功。
- 工具跳过、不支持或近似处理的必要内容，用适用方法补查并保留依据。
- 不支持的工艺不能改填为工具支持的默认工艺来取得通过。
- 修复后重新检查，最终提交版本保留完整DRC与适用DFM结果。
- 需要厂商解析才能完成的检查，先导出检查文件并按已有授权上传。
- 解析通过前不提交订单。

返回报告版本、输入工艺、逐项结果、补查依据及未解决事项，供项目阶段验收使用。
工具覆盖范围内通过不能代替全部制造要求通过。
