# 操作风险与结果判读

本页记录不能只看 `/help` 参数表判断的风险。常规操作见[原理图指令](commands-schematic.md)、[PCB 指令](commands-pcb.md)和[器件库指令](commands-lib.md)。

## 写入结果

- SDK 返回成功、非空 ID、截图或无 DRC 错误，都不能单独证明任务完成。按插件读回、目标内容和需要的保存重开核对。
- 超时不代表写入取消。结果未知时停止依赖写入，先用 `task.get`、列表或有效文档源码只读核对，不盲目重发。
- 删除后单对象 `get()` 可能读到缓存；用全量列表或有效源码确认。创建后列表也可能暂时漏项，结合返回 ID 核对。
- 没有通用撤销 API。破坏性操作前确认备份文件确实生成；关闭页签选择“不保存”不保证回滚。
- `TEXT` 即时删除后保存重开可能按原 ID 复活。返回的即时删除状态不证明持久删除；读回不完整或结果未知时停止，不改用整页源码写回，也不重试或补偿。
- 无界面环境的 `save` 成功返回不等于文件落盘，也不表示插件支持无头运行。

## 窗口和文档

- 每条 `/command` 都带当前核实的顶层 `instanceId`。`/help` 按全局所选窗口读取，须核对目标窗口的参数。
- `project.create`、`project.open` 会切换当前活动工程；切换前确认未保存修改的处理方式，完成后用 `project.getInfo` 核实。
- `project.getDocumentSource` 只读当前激活文档。先打开目标页并核对 `DOCHEAD.uuid`；源码坐标不能直接当公开 API 坐标，原理图 Y 轴方向相反。
- 源码日志须按有效记录判断对象；旧记录和删除墓碑不能视为当前状态。
- `project.modifyTitleBlock` 只改现有字段。提交接受不等于保存生效；纸张大小和图框符号不能靠此接口切换。

## 原理图和网表

- 放置指定 `deviceUuid` 时同时提供匹配的 `libraryUuid`。即时放置核验不代替保存重开、网表和 PCB 可用性检查。
- 修改器件时保留现有属性及 `otherProperty`。空字符串封装、裸封装名或缺失资源引用可能造成网表异常；导出后检查器件是否齐全。
- 连线避开第三方引脚和异网导线共线；宿主可能合并相接导线。已命名的 `drawWire` 不需叠加同名标签。用标签 ID、父导线和属性读回确认附着，视觉靠近不算连接。
- `getNetlist` / `exportNetlist` 可能更新位号、Unique ID 或保存工程，不是无副作用的纯读取。JLCEDA 类型使用文件生成通道；失败或超时不回退、不重发，先确认原调用结果。
- `dedupeWireNets` 只处理同一导线上的重复同名属性，不替异名冲突选择网络。重建可能改变图元 ID，之后重新查询。
- 完整器件更换按[原理图指令中的组合流程](commands-schematic.md)先放新件并核对，再删旧件。PCB 更新由用户在 EDA 界面发起并确认。
- 原理图视觉检查优先用 `schematic.exportPng`；后台 `editor.screenshot` 可能是旧帧。

## 器件库和工程树

- 库资源修改后 UUID 可能变化。以修改回包中的 UUID 和新鲜 `get`/搜索结果为准；`verify:"none"` 表示 SDK 修改返回成功但读回未确认，不能报告为已核实，也不要自动补写或重试。
- `lib.*` 查询省略 `libraryUuid` 时默认个人库；`footprintGetSource` 是例外，省略时按工程库再个人库查询，显式指定时只查该库。`library.searchDevice` 使用 SDK 默认搜索范围。限定来源时显式指定库并核对返回的库 UUID。
- 器件存在不代表有封装或可转 PCB。检查 `footprintUuid`、符号引脚与封装焊盘映射；诊断或放置的成功标志只覆盖其标明的检查范围。
- 工程恢复或导入后 UUID 可能重建。按图页、器件、网络和必要资源比较，不以旧 UUID 相等作为唯一条件。
- `project.importFile` 调用后空返回或异常代表结果未知；先按目标名称、目录和工程树查现场，不凭同名认定成功，不重复导入。

## PCB

- PCB DRC 不检查全部本体和丝印重叠。`checkPlacement` 是焊盘包围盒近似；有跳过对象或 `complete:false` 时不能称布局通过。
- 覆铜边框不表示已实填充。`filled` 未知不能当空或当完成；重铺后核对保存态和目标区域。
- `ComponentPad.getConnectedPrimitives` 不返回 `Poured`，不能证明焊盘与实覆铜接触或不接触。
- 自动布线回灌可能清除未锁定走线；先核对任务、锁定范围和回灌结果。普通 SES 导入不应套用同一清线假设。
