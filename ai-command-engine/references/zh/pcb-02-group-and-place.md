# PCB 2 · 器件分组与布局

具体参数、默认值、回包和示例以目标窗口的 `__help` 为准。

## 摆放器件

### 摆放顺序

1. 先放固定接口和机械相关器件。
2. 按供电、控制、采样和外接接口确定功能区的相邻关系。
3. 先安排旁路、驱动、自举、反馈和时钟等关键局部电路。
4. 为主电流、重要信号、换层孔和返回路径留出空间。
5. 根据全部已用接口调整主控位置和朝向。
6. 核对一个重复通道后，再展开其他通道。
7. 检查受限引脚出口和共用通道能否布线。
8. 最后调整普通器件的间距、朝向和对齐。

### 功能区和配套器件

- 关键芯片按对应型号、封装和工况的原厂布局要求检查。
- 分清原厂必须条件、建议和本项目采纳的做法。
- 把要求落实到具体焊盘、走线和返回路径。
- 不照搬示例板坐标、固定距离、网格或旋转角度。
- 选用分组时按真实连接关系整理，不只按位号前缀或器件种类分组，也不在铜层或丝印层自动画区框；未选用仍按真实连接、焊盘和返回路径布局。
- 每个配套器件明确所属引脚、接口或回路。
- 配套器件跟随真实引脚和返回路径摆放，不围绕芯片中心排队。
- 频繁互连的功能区先安排相邻位置和连接通道。
- 移动或旋转主控时，核对全部已用接口、配套器件和邻区影响。
- 飞线交叉、中心距离和总飞线长度只用于筛选候选。

### 各类局部电路

具体型号要求由 component-pcb-profiles 维护。
未核实的型号要求先查对应原厂资料。

| 对象 | 摆放检查 |
|---|---|
| 去耦与供电 | 检查对应供电脚、焊盘、过孔和返回组成的实际路径，不只看电容距离。 |
| 电源转换 | 按输入、转换和输出安排路径，并检查高频回路、自举、反馈和散热空间。 |
| 驱动与功率开关 | 检查驱动和开关回路，并避免功率路径干扰栅极与检测路径。 |
| 晶振与时钟 | 围绕时钟引脚安排晶体和负载器件，护地及下方布线按具体指南处理。 |
| 通信接口 | 保护、端接和分支按实际作用位置及接口拓扑摆放。 |
| 保护与续流 | 检查保护点、故障来源、返回和受保护路径的位置关系。 |
| 模拟与传感 | 输入、参考和滤波避开干扰，传感器位置和轴向符合测量目的。 |
| 分流与精密反馈 | 按实际取样端安排器件，并检查功率压降和热源的影响。 |

位号位置、角度、字号和显隐用 `pcb.modifyComponentAttribute` 修改，位号文本保持；安装孔与独立焊盘分别用 `pcb.placeHole`、`pcb.placePad`。按当前窗口帮助核对孔型、镀层、铜及阻焊，并读回几何和网络；不能用普通过孔代替NPTH安装孔。

### 散热、装配和对齐

- 热源附近的器件核对实际温度条件和允许温漂。
- 为散热铜、散热孔、散热器和实际气流留空间。
- 不为分散热源而拆散必须紧凑的功率或驱动回路。
- 大件按真实本体和装配空间检查，不只看焊盘包围盒。
- 双面和多层板检查全部受影响层的障碍、穿板引脚及配合结构。
- 小器件两端的铜连接和受热差异按实际焊接工艺检查。
- 电气和机械条件允许时，同类器件可统一朝向和间距。
- 不为整齐拉长关键回路，或仅因任意角度和不等距判错。
- 极性和 1 脚标识应便于装配和检查。
- 机械、安全、电气和制造的必要条件冲突时调整方案，不按固定排名豁免要求。

### 重复通道和复制

- 模板先明确输入、输出、控制、配套器件和返回关系。
- 每个实例核对脚号、极性、网络、朝向及所在位置的障碍。
- 共享供电和共享返回单独检查。
- 有实际障碍或工况差异时，允许通道采用不同摆法。
- 复用过孔布局后，逐通道核对网络、障碍、载流和散热条件。
- 模板通过不能代替全部实例检查。

## 烧录和测试位置

- 布局时先为烧录夹具、探针和拆焊工具留出空间。
- 按实际测试阶段，检查装配后能否接触到焊盘。
- 避开会挡住探针的连接器、散热器、屏蔽罩和外壳。
- 按所用探针或夹具确定焊盘尺寸、间距和接触面。
- 探针接触区开阻焊窗，并检查实际导出结果。
- 裸探针焊盘通常不开锡膏窗，焊线或其他工艺另按用途设置。
- 丝印标清必要的针序、信号和方向，不覆盖接触区。
- 烧录焊盘的顺序和方向与夹具一致，并考虑防反接。
- 测量点附近提供合适的参考地接触位置。
- 参考地必须属于被测电路，不跨接不同隔离域。
- 高速、射频、晶振和敏感模拟节点先评估测试焊盘及支线的影响。
- 探头负载可能改变信号，测量方式也要一起考虑。
- 0Ω 电阻放在便于拆装的位置，并保留两端测量空间。
- 需要断开的连接不能被铜面或其他支路绕过。
- 电源路径上的 0Ω 电阻及两端走线要满足实际载流要求。
- 核对所有烧录焊盘和测试点的实际焊盘网络。

## 分组和移动前后核对

- `pcb.moveComponent` 后核对位置、角度、面和锁定状态。`pcb.checkPlacement` 基于可读取的焊盘边界，跳过或不支持的对象不能当成布局通过。
- 原理图导入/更新已读回且来源可核对时，分别询问是否标记功能区或移动器件分组。沿用明确选择；未获授权不执行。详见[可选功能与提示时机](pcb-01-read-board-and-rules.md#可选功能与提示时机)。

## 标记和定位原理图功能区

这些指令使用当前 PCB 所关联原理图中的功能框，只标记或定位/高亮功能区，不移动器件。

1. 打开目标 PCB，调用 `pcb.getSchematicRegions` 读取功能区成员和未匹配对象；核对时包含锁定成员。
2. 调用默认 `dryRun:true` 的 `pcb.markSchematicRegions` 预览标记，并检查功能区和成员。
3. 只有用户明确同意后，才用 `dryRun:false` 调用 `pcb.markSchematicRegions` 执行。读回结果，再保存、关闭、重开并核对标记。
4. 用 `pcb.locateSchematicRegion(regionId)` 定位/高亮功能区。此指令不写入设计数据。

菜单项为“标记功能区（不移动元件）…”和“定位／高亮功能区…”。这与会移动器件的 `pcb.groupBySchematicRegions` 分开；不要默认调用。完整参数和回包以 `__help` 为准。

## 移动器件分组

`pcb.groupBySchematicRegions` 会移动器件并创建分组。仅在用户明确选择移动器件分组后使用，并先核对预览、板框容纳情况和影响；这不是上面的功能区标记流程。分组写后恢复未确认时，错误会带 `cause.partial:true` 和备份 ID。继续前先检查原 PCB 的实际状态。宏即使设置为普通错误后继续，也会停止依赖写入。

PCB 有变化或预览过期时，重新核对当前板并重新预览。结果未知时先检查实际状态。

## 布线前检查布局

读取真实焊盘、面、位置和方向，按固定接口、关键局部电路、全部已用接口及返回路径安排功能组；需要重复通道时逐实例核对。分组不等于在铜层或丝印层画功能框，也不要求每次调用自动分组宏。

用 `pcb.checkPlacement`、当前顶底面/局部图及适用机械资料检查本体和装配空间；该命令仅以可读焊盘边界筛查，跳过项和近似候选需补查。受限焊盘出口、共用通道、过孔和全层障碍按线组检查，不能仅凭器件不重叠或飞线更短就开始正式布线。发现问题先局部调整，不重排无关区域。

## 命令索引

| 任务 | 命令 | 用途 |
| --- | --- | --- |
| 原理图功能区标记和高亮 | `pcb.getSchematicRegions`、`pcb.markSchematicRegions`、`pcb.locateSchematicRegion` | 读取功能区成员；预览标记（默认 `dryRun:true`）；明确授权后执行（`dryRun:false`）；或只定位/高亮，不写设计数据。 |
| 摆放与板框 | `pcb.moveComponent`、`pcb.checkPlacement`、`pcb.drawOutline` | 移动器件、检查布局间距和建立板框。 |
| 移动器件分组和恢复 | `pcb.groupBySchematicRegions`, `pcb.sourceRollback` | 仅在明确选择后移动器件创建分组；恢复前核对目标及备份。 |
