# 写入结果不明与拆并线核对

1. 修改前核对工程、图页和对象。局部改线或涉及已验收内容时先备份，保留网络、图层、端点、线宽、过孔及关键接点。
2. 超时、部分失败或回执不全时，先停相关写入，再查原任务和当前图页。仍在运行或结果未确认时保留现场，不重放整批。
3. 按网络、图层、端点、线宽、接头和实际占铜范围对账。核查宿主拆并线、T 形分段、支路、换层和焊盘接触。已有较宽线路只有确实覆盖路径且符合规则时，才计作复用。
4. 保存重开或导出后，单独记录图元编号变化。过孔读回取整时，用同板同对象的有效源码核对精确尺寸和单位。保留原读数与精确值。
5. 依据读回列出新建、复用、拆分、合并、缺失和未确认。确认原任务结束且缺失明确后，只补授权范围内的缺失部分。其他情况保留现场或使用已确认适用的恢复方法。

使用 `pcb.listLines`、`pcb.listVias`、`project.getDocumentSource` 等可用读回，局部用 `pcb.reviewLocalRouting` 辅助。结合当前帮助确认覆盖范围。自动分类缺失时从数据整理，不能假设插件会识别所有拆并线。原理图恢复核对以真实引脚、共享支路和逐脚网络为准。
