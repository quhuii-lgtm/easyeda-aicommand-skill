# Task-Specific PCB Commands

This index groups less common tasks; it does not indicate a command is unusable or unverified. Check the active window with `GET /help?cmd=<command>`. See [PCB command details](commands-pcb.md) and [PCB special topics](commands-pcb-special.md).

| Task | Commands | Purpose and limits |
| --- | --- | --- |
| Autorouting and import | `pcb.autoRouteStart`, `pcb.autoRouteStatus`, `pcb.autoRouteGetResult`, `pcb.autoRouteStop`, `pcb.exportDsn`, `pcb.importAutoRouteSes` | Start/check routing, export DSN, and import SES. Retrieving a result does not import it; verify target board and source before import. |
| Fanout and local routing | `pcb.getFanoutPlan`, `pcb.fanout`, `pcb.getPadExpansionPlan`, `pcb.expandPads`, `pcb.routePadBranches`, `pcb.routeDiffPair` | Plan or execute fanout, pad expansion, branches, and differential routes. Inspect plan and target nets first. |
| Auto copper and net labels | `pcb.getAutoCopperPlan`, `pcb.autoCopper`, `pcb.getPourFillReadback`, `pcb.getNetSilkscreenPlan`, `pcb.generateNetSilkscreen`, `pcb.groupBySchematicRegions`, `pcb.sourceRollback` | Plan or create copper, net silkscreen, or schematic-region groups. Check source records and target before rollback. |
| Text and primitives | `pcb.listStrings`, `pcb.placeString`, `pcb.modifyString`, `pcb.listLines`, `pcb.modifyLine`, `pcb.listVias`, `pcb.modifyVia`, `pcb.modifyPour`, `pcb.delete` | Read or modify text, lines, vias, pours, or delete a specified primitive. Read back by ID after writing. |
| Net queries and export | `pcb.getNetRules`, `pcb.getNetLength`, `pcb.getNetPrimitives`, `pcb.highlightNet`, `pcb.setNetLock`, `pcb.exportNetlist` | Inspect rules, length, and primitives; lock a net or export a netlist. Preserve unknown status when rule information is incomplete. |
| Net classes and length groups | `pcb.createDiffPair`, `pcb.listDiffPairs`, `pcb.deleteDiffPair`, `pcb.createNetClass`, `pcb.listNetClasses`, `pcb.addNetToClass`, `pcb.removeNetFromClass`, `pcb.deleteNetClass`, `pcb.renameNetClass`, `pcb.createEqualLengthGroup`, `pcb.listEqualLengthGroups`, `pcb.renameEqualLengthGroup`, `pcb.deleteEqualLengthGroup`, `pcb.addNetToEqualLengthGroup`, `pcb.removeNetFromEqualLengthGroup` | Manage net classes, differential pairs, and equal-length groups. Deleting a net class does not guarantee prior net colors are restored. Verify targets before changes. |
| Layers and stackup | `pcb.getCurrentLayer`, `pcb.selectLayer`, `pcb.setCopperLayers`, `pcb.setLayerVisible`, `pcb.setLayerLocked`, `pcb.listStackingConfigs`, `pcb.getStackingConfig`, `pcb.applyStackingConfig`, `pcb.saveStackingConfig`, `pcb.renameStackingConfig`, `pcb.deleteStackingConfig`, `pcb.setDefaultStackingConfig`, `pcb.addCustomLayer`, `pcb.removeCustomLayer`, `pcb.modifyLayer`, `pcb.setPcbType` | Inspect or set active layer, copper count, layers, and stackup. EDA 4.1.78 rejects `getCurrentLayer`, stackup commands, and real-time DRC commands with an EDA 4.2 requirement. A rejection is not a successful check. |
| Selection and cross-probe | `pcb.getSelection`, `pcb.select`, `pcb.clearSelection`, `pcb.crossProbe`, `pcb.getPrimitivesInRegion`, `pcb.getPrimitiveAtPoint` | Read or change selection, cross-probe, or locate primitives by region or point. |
| Sync and checks | `pcb.importChanges`, `pcb.checkManufacturingProfile`, `pcb.runDrcDetailed` | The user initiates and confirms schematic-to-PCB updates in EDA; AI does not call `importChanges`. The other commands check manufacturing profile or return detailed DRC. |
| Special checks and tuning | `pcb.tuneLength`, `pcb.inspectCurveReadback` | Inspect or adjust curve and trace length. Check current help for supported parameters and host support. |

On EDA 4.1.78, these commands have explicit EDA 4.2 version guards: `pcb.getCurrentLayer`, `pcb.listStackingConfigs`, `pcb.getStackingConfig`, `pcb.applyStackingConfig`, `pcb.saveStackingConfig`, `pcb.renameStackingConfig`, `pcb.deleteStackingConfig`, `pcb.setDefaultStackingConfig`, `pcb.startRealTimeDrc`, `pcb.stopRealTimeDrc`, and `pcb.getRealTimeDrcStatus`. Execution, saving, and readback still need confirmation on a supported version.
